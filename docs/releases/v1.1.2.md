# LinkLake v1.1.2

## 中文

v1.1.2 是面向 v1.1.1 的兼容性补丁发行，锁定 `h2` 与 `chacha20` 相关安全依赖，并修复严格 Clippy 门禁与跨平台测试夹具问题；不改变 v1.1 已发布的协议、存储迁移、配置或高可用语义。

### 主要变化

- **安全依赖锁定**：刷新 Rust lockfile 和第三方许可证清单，固定 `h2` / `chacha20` 依赖路径的安全更新版本。
- **发布质量**：修复严格 Clippy 发布门禁反馈，并统一 Windows 与 Unix 测试夹具的临时路径处理。
- **版本身份**：Server、Client、Manager、Windows 文件资源、Helm Chart 与仓库文档统一标记为 `1.1.2`，便于安装器、更新器和部署工具精确匹配。
- **兼容性**：沿用 v1.1.1 的数据库 schema、配置格式、更新协议和运行边界；不需要新的迁移步骤。

### 升级与运行边界

从 v1.1.1 升级时，按既有[使用说明](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.2/docs/user-guide.zh-CN.md)、[部署指南](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.2/docs/deployment.md)和[发布供应链说明](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.2/docs/release-supply-chain.zh-CN.md)核对包版本、校验和、签名以及数据库和实例目录备份。生产节点升级仍需根据各自维护窗口和恢复方案安排。

v1.1.1 与 v1.1.0 的历史说明保留在[旧版发行记录](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.1/docs/releases/v1.1.1.md)和[更早版本记录](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.0/docs/releases/v1.1.0.md)，对应标签语义不变。

## English

LinkLake v1.1.2 is a compatibility patch release for v1.1.1. It pins security-updated `h2` and `chacha20` dependency paths and fixes strict Clippy gate findings plus cross-platform test-fixture paths without changing the v1.1 protocol, storage-migration, configuration or high-availability semantics.

### Changes

- **Security dependency locks:** Refresh the Rust lockfile and third-party license inventory, pinning the security-updated `h2` / `chacha20` dependency paths.
- **Release quality:** Fix strict-Clippy release-gate findings and make temporary-path handling consistent across Windows and Unix test fixtures.
- **Version identity:** Server, Client, Manager, Windows file resources, the Helm chart and repository documentation now consistently report `1.1.2` for exact installer, updater and deployment matching.
- **Compatibility:** The v1.1.1 database schemas, configuration formats, update protocol and operational boundaries remain in effect; no new migration step is required.

### Upgrade and operational boundaries

When upgrading from v1.1.1, follow the existing [user guide](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.2/docs/user-guide.en.md), [deployment guide](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.2/docs/deployment.md) and [release supply-chain guide](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.2/docs/release-supply-chain.md) to verify package versions, checksums, signatures, database backups and instance-directory backups. Schedule production upgrades around each environment's maintenance window and recovery plan.

The v1.1.1 and v1.1.0 historical notes remain in the [previous release record](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.1/docs/releases/v1.1.1.md) and the [earlier release record](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.0/docs/releases/v1.1.0.md); their existing tag semantics are unchanged.
