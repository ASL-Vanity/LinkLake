# LinkLake v1.1.1

## 中文

v1.1.1 是面向 v1.1.0 的兼容性补丁发行，统一产品版本元数据并刷新发布门禁依赖；不改变 v1.1.0 已发布的协议、存储迁移或高可用语义。

### 主要变化

- **依赖与供应链**：更新锁定的 Rust 依赖版本和发布门禁资料，保持安全审计、许可证和资产身份检查可重复执行。
- **版本身份**：Server、Client、Manager、Windows 文件资源、Helm Chart 与仓库文档统一标记为 `1.1.1`，便于安装器、更新器和部署工具进行精确匹配。
- **兼容性**：沿用 v1.1.0 的数据库 schema、配置格式、更新协议和运行边界；不需要新的迁移步骤。

### 升级与运行边界

从 v1.1.0 升级时，按既有[使用说明](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.1/docs/user-guide.zh-CN.md)、[部署指南](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.1/docs/deployment.md)和[发布供应链说明](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.1/docs/release-supply-chain.zh-CN.md)核对包版本、校验和、签名以及数据库和实例目录备份。生产节点升级仍需根据各自维护窗口和恢复方案安排。

v1.1.0 的历史说明保留在[旧版发行记录](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.0/docs/releases/v1.1.0.md)，对应标签语义不变。

## English

LinkLake v1.1.1 is a compatibility patch release for v1.1.0. It aligns product metadata and refreshes release-gate dependencies without changing the v1.1.0 protocol, storage-migration or high-availability semantics.

### Changes

- **Dependencies and supply chain:** Refresh the pinned Rust dependency set and release-gate metadata so security, license and asset-identity checks remain reproducible.
- **Version identity:** Server, Client, Manager, Windows file resources, the Helm chart and repository documentation now consistently report `1.1.1` for exact installer, updater and deployment matching.
- **Compatibility:** The v1.1.0 database schemas, configuration formats, update protocol and operational boundaries remain in effect; no new migration step is required.

### Upgrade and operational boundaries

When upgrading from v1.1.0, follow the existing [user guide](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.1/docs/user-guide.en.md), [deployment guide](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.1/docs/deployment.md) and [release supply-chain guide](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.1/docs/release-supply-chain.md) to verify package versions, checksums, signatures, database backups and instance-directory backups. Schedule production upgrades around each environment's maintenance window and recovery plan.

The v1.1.0 historical notes remain in the [previous release record](https://github.com/ASL-Vanity/LinkLake/blob/v1.1.0/docs/releases/v1.1.0.md), and the existing tag semantics are unchanged.
